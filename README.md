# LogiSight – Logistics Analytics Dashboard

## Project Overview

LogiSight is an interactive logistics analytics dashboard designed to monitor and analyze last-mile delivery performance. It provides meaningful insights into delivery efficiency, operational delays, vehicle performance, delivery agents, and regional logistics trends.

The application transforms delivery data into interactive visualizations and key performance indicators, helping logistics managers identify operational patterns and make informed decisions.

## Problem Statement

Last-mile delivery operations are influenced by several factors, including weather conditions, traffic congestion, vehicle types, delivery agent performance, geographical areas, and product categories.

These factors can contribute to longer delivery times, operational inefficiencies, and inconsistent delivery performance.

Without a centralized analytics platform, logistics managers may find it difficult to identify the conditions associated with delivery delays, compare operational performance, and recognize areas requiring improvement.

The challenge is to transform complex delivery data into clear, accessible, and actionable insights that support better logistics management.

## Proposed Solution

LogiSight addresses these challenges by providing an interactive dashboard that consolidates delivery performance information into a single platform.

The application enables users to monitor key performance indicators, analyze delivery delays, compare vehicle and agent performance, and explore regional and product-category trends.

Through interactive visualizations and dynamic filters, users can investigate delivery performance under different operating conditions and identify potential opportunities for improving efficiency.

## Application Features

### 1. Operations Command Center

* Displays total deliveries, average delivery time, late-delivery percentage, and average agent rating.
* Provides visual comparisons of delivery performance across weather and traffic conditions.
* Displays the distribution of delivery durations.

### 2. Delay Intelligence

* Analyzes average delivery times under different weather and traffic conditions.
* Uses interactive grouped bar charts to identify conditions associated with longer delivery durations.
* Highlights traffic conditions with higher average delivery times.

### 3. Fleet and Agent Analytics

* Compares delivery efficiency across vehicle types using colorful bar charts.
* Identifies vehicles associated with lower average delivery durations.
* Examines relationships between agent ratings, age groups, and delivery times through interactive scatter plots.

### 4. Regional and Product Insights

* Uses a heatmap to compare average delivery times across delivery areas.
* Highlights regions associated with longer delivery durations.
* Uses box plots to analyze delivery-time variations across product categories.

### 5. Interactive Filters

* Allows users to filter delivery records by weather, traffic, vehicle, product category, and delivery area.
* Automatically updates dashboard metrics and visualizations based on selected filters.
* Includes a reset option to restore the complete dataset.

### 6. Data Quality and Exploration

* Provides an overview of the data preparation process.
* Displays data quality summaries and missing-value information.
* Allows users to explore delivery records and download filtered data.

### 7. User-Friendly Interface

* Provides organized navigation between dashboard sections.
* Supports dark and light themes.
* Includes interactive charts, performance indicators, and a dashboard guide.

## Conclusion

LogiSight provides a centralized platform for understanding last-mile delivery performance through interactive analytics and visualizations.

By combining delivery performance indicators, delay analysis, fleet comparisons, agent performance insights, and regional analysis, the application makes complex logistics information easier to interpret.

The dashboard supports data-driven decision-making by helping logistics managers identify operational inefficiencies, monitor performance, and explore opportunities for improving delivery efficiency.
